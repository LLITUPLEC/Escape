Краткая сводка по достижениям из контекста последней работы (UI, клиент, матч) — без доступа к серверному Lua по достижениям отдельным запросом; ниже — как это устроено по коду.

Что сделано
Локально (Unity / C#)
Панель достижений: вкладки, скролл, строки цепочек из префаба, привязка к кнопке открытия, починка TMP (SubMesh / шрифт TF2CSecondary).
Модальное окно шага: по тапу по слоту цепочки открывается пояснение (условие + текст награды) — AchievementStepDetailModal, клик через Button на рамке слота (AchievementChainSlotView / AchievementChainRowView).
Хранение прогресса: AchievementProgressStorage — счётчики по ключам и список «полученных шагов» в PlayerPrefs (achievements.stats.v1, achievements.claimed_steps.v1).
Трекер: AchievementTracker — AddStat, уведомления способностей, победы турнира/дуэлей, финиш петардой, победа при 1 HP, NotifyDoubleFivePlusLinesSameTurn и NotifyWinAtOneHp; при достижении порога шаг помечается claimed и шлётся событие для toast.
**ДНН «две линии 5+ за ход»**: в **DuelMatch3Manager** локально считаются сегменты с match.count >= 5за один разрешённый ход (swap / крест / квадрат + каскады); при **≥ 2** вызываетсяNotifyDoubleFivePlusLinesSameTurn()— **только в локальной симуляции** (режим с ботом), где вызываетсяResolveLocalAction`.
Бонусы в бою из достижений: класс AchievementCombatBonuses — по claimed шагам начисляются плоские и «процентные» бонусы к уже пришедшим с сервера PlayerStats после синка доски (аппроксимация процентов «от экипировки» через долю от текущих базовых статов).
Исправление синтаксиса: восстановлен метод ResolveCascades в DuelMatch3Manager (раньше после правки пропала сигнатура метода).
Серверная логика по достижениям
В обсуждавшемся объёме отдельной серверной системы достижений в Nakama/Lua не описывалось: счётчики и claimed шагов — на клиенте. Сервер по-прежнему отдаёт матч и статы (M3BoardSyncMsg и т.д.); ДНН по двум линиям 5+ на онлайн-матче без дублирования логики на клиенте явно не подключали (RNG каскадов на сервере).
Правила зачисления условий (по сути)
Условие	Где фиксируется
Использование способностей в матче
NotifyAbilityUsedMatch3 из синка / локально
Победы турнира кузнеца, дуэлей, финиш петардой, 1 HP
После матча / из логики матча (DuelMatch3Manager, AchievementTracker)
Две линии 5+ за ход
Локальный подсчёт в ResolveLocalAction + уведомление трекера
Шаг «получен»
Когда счётчик ≥ порога и шаг ещё не claimed — MarkStepClaimed + toast
Что не сделано / ограничения
Золото / руда / материя из текстов наград — не выдаются автоматически через Nakama (нужен RPC или вызов при EvaluateChain).
Экран персонажа / шахта: те же бонусы в UI инвентаря не подключались — только PlayerStats в матче после синка.
Онлайн PvP: достижение ДНН по двум линиям 5+ не полагается на симуляцию клиента без серверного счётчика или поля в сообщении синка.
Точные проценты «от экипировки» — на клиенте упрощены (доля от уже синхронизированных базовых статов).
Если нужно, в Agent mode можно точечно доработать сервер (duel_match3.lua) или выдачу ресурсов по RPC.
