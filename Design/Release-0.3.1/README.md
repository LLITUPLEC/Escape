# Escape 0.3.1 — компоновка интерфейса и звуки боя

Патч уточняет интерфейс версии 0.3.0 и обновляет звуковой отклик. Изменения игровых цен, баланса и серверных правил в этот список не входят.

## Исправления интерфейса

- В полях аккаунта исправлены отступы текста и `Placeholder`: ввод и подсказки располагаются внутри поля.
- Группы ресурсов в шапке и индикатор `Online` центрированы в своих областях.
- Характеристики героя собраны в пять равных колонок. Счётчик количества предмета получил внутренний отступ, включая позднее создаваемый `StackLabel`.
- В досье монстра согласованы отступы характеристик, аффикса и наград; портрет помещается в рамку.
- Требования барьера показываются отдельными карточками в прокручиваемой области.
- В боевом HUD уточнены размеры и расположение портретов; заполнение HP и маны находится внутри рамок. Таймер центрирован отдельно от подписи хода и аффикса.
- Для квадратных исходников с монстром в полный рост боевой портрет кадрирует голову, сохраняя её читаемый размер в рамке.
- Всплывающие значения лечения и маны ограничены видимой областью своих панелей.
- В подсказке аффикса разведены заголовок, основной текст и кнопка закрытия.
- Окно результата получило непрозрачную подложку и затемнение фона. Иконки и значения наград увеличены; длинный список прокручивается.
- Динамическая стоимость маны располагается внутри нижнего правого бежевого угла оригинального спрайта способности. Иконки способностей сохранены; стоимость берётся из действующего состояния игры.

Их контрольные суммы, длительности/уровни новых клипов и отсутствие отсечённых отсчётов записаны в [validation/audio-assets.json](validation/audio-assets.json). Версия **0.3.1 опубликована** на [prokrust-play.ru/escape](https://prokrust-play.ru/escape/). [APK — 94,7 МиБ](https://prokrust-play.ru/escape/downloads/Escape-0.3.1-ccb206869600.apk), код версии 3, ARMv7/ARM64. Результаты UI зафиксированы в [validation/ui-qa.json](validation/ui-qa.json): Unity 6000.3.9f1 Editor Play Mode, 1440×3088.

- На настоящих игровых экранах проверены шапка убежища, герой/инвентарь, досье монстра и барьер, порядок и прокрутка этажей шахты, HUD соло-боя, кадрирование портретов и подсказка аффикса. Барьер не открывался. Форма аккаунта проверялась настоящим рендерером с отключённой тестовой формой, без отправки авторизации.
- C# для Runtime, Editor и Android Player проверен Roslyn с соответствующими условными определениями. Это проверка компиляции скриптов; результат нативной сборки APK учитывается отдельно.
- Длинные и пограничные состояния проверены локальными презентационными fixtures с рабочими компонентами UI: длинный аффикс и шесть карточек барьера прокручиваются до конца; значок щита отделён от характеристик; заполнение HP/маны проверено при 0/50/100%; динамическая стоимость — на двух наборах значений; одновременные всплывающие лечение/мана остаются в видимой области. Эти проверки не обозначаются как реальные боевые события.
- Окно результата проверено отдельным fixture настоящего рендерера наград: четыре награды центрированы, двенадцать прокручиваются до последней. Бой для этой проверки не завершался, награды не запрашивались и не получались.
- Локально сверены контрольные суммы всех 12 клипов с аудиоотчётом: расхождений нет, в отчёте у каждого клипа 0 отсечённых отсчётов. Отдельно подтверждено совпадение хешей критического звука и его `.meta`.
- В настоящем менеджере боя проверены импорт и назначение всех 13 SFX: 12 обновлённых клипов и сохранённый критический звук. Это не проверка звучания через динамики телефона.
- [Проверка APK](validation/apk-validation.json) завершилась успешно: релизная сборка без ошибок, версия 0.3.1, код 3, ARMv7/ARM64, данные Unity, отсутствие отладки, подпись v2, размер и SHA-256. Сборка выдала два предупреждения.
- [Публичная проверка](validation/public-release.json) имеет состояние `passed`: страница и манифест HTTP 200, APK HEAD 200 и диапазон 206, корректные размер/MIME/кэш, прежний APK 0.3.0 доступен, API отвечает HTTP 200. [Полный SHA-256 серверного файла](validation/server-apk-hash.json) совпал с локальным APK. [Публикация](validation/deploy-result.json) прошла без изменения конфигурации прокси.
- В браузере проверены новая версия, журнал изменений, обновлённый скриншот героя и открытие/закрытие галереи. [Кадр опубликованной страницы](validation/public-page.png) сохранён.
- Проверка на физическом Android-устройстве **не выполнялась** (`physical_device_tested=false`). Не подтверждены ощущение звука через динамики телефона, сенсорное управление и производительность на конкретном устройстве.

## Подготовка и последующий запуск

Из корня репозитория можно подготовить отчёт без обращения к серверу:

```powershell
& .\Tools\Release\verify-public-release.ps1 `
  -ExpectedVersion '0.3.1' `
  -PreviousApkUrl 'https://prokrust-play.ru/escape/downloads/Escape-0.3.0-17e666a68265.apk' `
  -PreviousApkBytes 99453871 `
  -PrepareOnly
```

После подтверждённой сборки и отдельной публикации команда без `-PrepareOnly` выполняет реальные HTTP-проверки. Локальные пути задаются через `-ManifestPath`, `-ApkDirectory`, `-ReportPath`; адреса — через `-BaseUrl`, `-HealthUrl`, `-PreviousApkUrl`. Предыдущий APK остаётся доступным по своей прежней ссылке; проверка HEAD не удаляет и не заменяет его.

Полный публичный APK HTTP-скрипт не скачивает. Он сверяет хеш локального файла с манифестом, затем публичный манифест с локальным и проверяет заголовки/первые четыре байта серверного файла. Для этого релиза полный серверный SHA-256 дополнительно проверен через SSH. Отчёты проверок не публикуются вместе со статической страницей.
