# Escape 0.3.5 — читаемый интерфейс и прогнозы турнира

Документ описывает изменения по десяти замечаниям пользователя. **Unity Play UI QA и окончательная Android IL2CPP-сборка пройдены.** Гонка ответа ставки со старым poll воспроизведена и исправлена; проверены принятый выбор, отказ следующего выбора и отмена. Результаты проверки опубликованных файлов фиксируются отдельно в `validation/public-release.json` и `validation/public-auditions.json`.

## Условия ставок

Включённая опция разрешает показ интерфейса, но не открывает закрытое сервером окно. Прогноз доступен до начала четвертьфинала и полуфинала, только в чужой текущей паре. Во время боя, в своей паре, в прошлых/будущих раундах и в финале новый выбор не разрешается. Уже выбранный прогноз закрытого раунда может показываться как недоступный для изменения. Подсказка объясняет закрытое окно или отсутствие прогнозов в финале; клиент не подменяет `bets_open` значением true.

Награды, стоимость участия и денежная политика турнира/«Спуска» этой итерацией не меняются. Серверные изменения для описанных исправлений интерфейса не требуются. Оплаченные production-турниры в рамках UI QA не создаются.

## Проверка и ограничения

- Подготовленные runtime и Editor исходники компилируются с настоящими Unity Roslyn references: exit 0/0. Проверка player-условий с Android defines, без `UNITY_EDITOR*`, `UNITY_INCLUDE_TESTS` и UnityEditor references также дала exit 0. Это управляемая компиляция, **не IL2CPP/APK build**. Логи находятся в `.utmp/expedition/validation-arena035/`.
- [Unity UI QA](validation/ui-validation.json), Unity 6000.3.9f1, Game View 1440×3088: пройдены три состояния цепочки достижений и повторный bind; восемь empty/busy/ready слотов мастерской; настоящее заполнение XP 0/50/100%; красный X на исходном callback с actual raycast; активная/неактивная серверная аура и настоящее окно; увеличенные боевые характеристики; аффикс и закрытие его подсказки. Это Editor-проверка интерфейса, не тест на физическом Android.
- Ставки проверены idle-only Editor fixture на **настоящих JSON DTO** из изолированного теста 0.3.4: snapshots 0–4. В открытом QF доступны три чужие пары, в открытом SF — одна, в трёх закрытых состояниях — ноль. Пройдены реальные renderer/raycast, исходные UI callbacks, точные слоты, A/B/повторное нажатие для отмены, rollback отказа и последующий poll, option OFF/ON и непересекающиеся UID-маршруты. **Последняя граница отправки запроса перехвачена в Editor**: тест не отправлял bet RPC и не входил в платный турнир. Исходный preference, UI и polling восстановлены. Это не end-to-end проверка сетевого порядка ответов или Android touch.
- Гонка запоздавшего poll исправлена и включена в окончательный APK. Живая Editor QA в QF и SF прошла через реальные Complete/Sync и production admission guard: A подтверждён, pending B сохранён, при отказе B восстановлен A, новая выборка допускается, принятая отмена остаётся пустой. Core before/after: 5 отказов старого кода, 8 успешных проверок исправленного; RPC перехвачен только в тесте.
- Прослушивание демо человеком, оценка на динамике телефона и выбор A/B ещё требуются. Автоматические peak/RMS/hash проверки не доказывают художественное качество звука.
- Физический Android, IME, touch/resume, длительные сетевые разрывы, FPS/GC и долгие турниры не подтверждены этой записью.
- [APK validation](validation/apk-validation.json) и [публичная проверка](validation/public-release.json) пройдены: версия/code/подпись/обе ABI/отсутствие debug, HTTP200, Range206, размер, SHA-256, прежний APK и API health. Полный SHA-256 серверной копии совпадает. Страница скачивания: https://prokrust-play.ru/escape/.
- [Read-only аудит аудиоупаковки](validation/static-audio-packaging-review.json) не выявил блокеров: в allowlist только HTML, 64 WAV и публичный manifest; inventory, логи и локальные пути не копируются. Все 64 ссылки существуют, reparse points отсутствуют, внешних зависимостей страницы нет. Это проверка исходников, не запуск упаковки или публикации.
