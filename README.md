# Escape

Unity-проект игры Escape. Текущий опубликованный выпуск — **0.3.16**, предыдущий — **0.3.15**. Версия Unity: **6000.3.9f1**.

## Структура

- `Assets/`, `Packages/`, `ProjectSettings/` — исходники и настройки клиента.
- `Server/nakama/` — серверные модули, канонические каталоги, миграции и тесты.
- `Website/escape/` — исходники страницы загрузки; `dist/` генерируется локально.
- `Tools/` — инструменты сборки, публикации, проверки, графики и звука.
- `Docs/Design/` — игровые спецификации; `Docs/References/` — исходные макеты.
- `Design/Audio/` — утверждённые звуковые исходники и история их выбора.
- `Design/Release-0.3.16/`, `Design/Release-0.3.15/` — материалы двух сохранённых выпусков.
- `Builds/<версия>/` — локальные проверенные APK, symbols и `build-status.json`.
- `.cache/` — локальные зависимости и воспроизводимые результаты проверок.
- `.local/` — приватные локальные файлы. Они исключены из Git.

Откройте корень проекта в Unity Hub. Локальный `Assets/_Project/Resources/NakamaConnectionConfig.asset` сохраняется отдельно от репозитория; сведения о подключении находятся в [серверной документации](Server/nakama/README.md).

## Проверки и выпуск

Серверные тесты находятся в `Server/nakama/tests/`, Unity-проверки — в `Assets/_Project/Editor/`. SDK для сборки подготавливает `Tools/Release/prepare-android-sdk.ps1`; локальная копия хранится в `.cache/android-sdk/`.

Сборка release APK: меню Unity `Tools/Escape/Expedition/Build Android release APK`. Выходные файлы появляются в `Builds/<версия>/`. Инструменты проверки и публикации расположены в `Tools/Release/`; порядок публикации описан в [README сайта](Website/escape/README.md).

## Хранение файлов

В рабочем дереве сохраняются два последних опубликованных выпуска, их APK и symbols. Старые сборки, staging-пакеты и воспроизводимые кеши можно удалять после проверки сохраняемых файлов. Рабочие исходники, игровые каталоги, тестовые фикстуры и приватные конфигурации не относятся к архивам релизов.

На VPS Escape сохраняются два выпуска сайта, два APK и две проверенные резервные копии. Очистка ограничивается каталогами Escape и не затрагивает другие проекты или Docker volumes. Отчёты последней очистки находятся в `Design/Release-0.3.16/validation/local-retention-result.json` и `Design/Release-0.3.16/validation/server/`.
